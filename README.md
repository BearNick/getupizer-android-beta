# GetUpizer Android Beta

Official public distribution point for invited GetUpizer Android beta testers — and we are looking for more testers (see below). This repository contains release APK files, tester instructions, release notes and public beta news only. Application source code and infrastructure are kept in a separate private repository.

## Download

Download the [latest Android beta](https://github.com/BearNick/getupizer-android-beta/releases/latest) and select the attached `.apk` file. Verify its SHA-256 digest against the value published in the release notes before installation.

Current public beta: **0.1.36 (build 37)**.

> **One-time reinstall from 0.1.23 or older.** Since 0.1.24 the beta is signed with a new release key. If you have 0.1.23 or older, uninstall it first, then install the latest beta and sign in again. Your account and content are kept on the server. Later betas update in place as usual.

## Testers wanted

We are looking for more beta testers — Android phones and the web app (an iOS build will follow). The quickest way is the form at **[getupizer.com/download#tester-access](https://getupizer.com/download#tester-access)**: leave your email and platform, confirm the address, and you will get an invitation once the request is approved. You can also write to **[support@getupizer.com](mailto:support@getupizer.com)** with the email address you want to use and your platform (Android / iPhone / web). You will get an invitation to register; no account details are needed in your message.

## Installation

1. Download the APK directly from the selected GitHub Release.
2. Android may ask permission to install apps from the browser or file manager used to open it.
3. Install the APK and sign in with your assigned GetUpizer test account.
4. Disable the temporary unknown-app installation permission afterwards if you do not normally use it.

## Feedback

Use [Issues](https://github.com/BearNick/getupizer-android-beta/issues) for reproducible beta feedback. Include device model, Android version, app version, expected result and actual result. Do not publish passwords, authentication codes, private messages, personal data or sensitive screenshots.

## Status

These APKs are pre-release builds for controlled testing and are not Google Play production releases. Google Play Internal Testing will be provided separately.
